# نهج AI

منصة تدريب مجانية تقود المعلم من صور صفحات كتابه إلى حقيبة درس كاملة (إنفوغراف، عرض، كويز، لعبة، مقطع قصير) باستخدام نماذج الذكاء الاصطناعي المجانية، مع مراجعة بشرية إلزامية.

- الحقيبة الأولى: **نهج الانطلاق** (مفتوحة)
- قيد الإعداد: **نهج التمكّن**، **نهج القمة**

إعداد وتدريب: أ. محمد التهامي — [قناة يوتيوب](https://youtube.com/@-mmss)

## التعديل
كل الإعدادات (روابط النماذج، نماذج Google، المقاطع) في كائن `CONFIG` داخل `index.html`. المقاطع توضع في مجلد `videos/` ويُكتب مسارها في `CONFIG.videos` أو `CONFIG.showcase`.
